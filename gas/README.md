# 禾煎線上訂單 × Google Sheet 串接說明

網站結帳送出後，訂單會透過 Google Apps Script（GAS）寫進 Google 試算表，並寄 Email 通知店家。

```
網站結帳 ──POST──▶ GAS 網頁應用程式（Code.gs）──▶ Google 試算表
                         │                         ├ 訂單（一筆一列，可改狀態）
                         │                         ├ 訂單明細（一個商品一列）
                         ├─▶ Email 通知店家        ├ 商品（價格以這裡為準）
                         └─▶ 每日營業報表          ├ 門市
                                                   └ 設定（通知信箱、運費、暫停接單）
```

## 一、建立試算表與程式（約 5 分鐘）

1. 到 [Google 試算表](https://sheets.new) 建立新的試算表，命名為「禾煎訂單」。
2. 上方選單 **擴充功能 → Apps Script**。
3. 刪除編輯器裡原本的內容，把本資料夾的 `Code.gs` 全部貼上，按 **儲存**。
4. 在上方函式下拉選單選 **`setup`**，按 **執行**。
   - 第一次會要求授權：選你的 Google 帳號 →「進階」→「前往（不安全）」→ 允許。
   - 這是你自己的程式，Google 對未經審查的個人腳本都會顯示這個警告。
5. 回到試算表，會看到 5 個工作表都已建立好，上方也多了「禾煎訂單」選單。

## 二、部署成網頁應用程式

1. Apps Script 右上角 **部署 → 新增部署作業**。
2. 齒輪圖示選 **網頁應用程式**，設定：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
3. 按 **部署**，複製「網頁應用程式網址」（`https://script.google.com/macros/s/.../exec`）。

## 三、連接網站

把網址貼到 `index.html` 裡這一行的引號中：

```js
const ORDER_API_URL = '';
```

或直接把網址告訴 Claude，由 Claude 幫你填入並發布。網址留空時，網站會維持原本的模擬結帳。

## 四、日常使用

| 想做的事 | 怎麼做 |
| --- | --- |
| 看新訂單 | 開「訂單」工作表；也會收到 Email 通知 |
| 更新訂單進度 | 「狀態」欄下拉選：新訂單 → 製作中 → 可取餐／已出貨 → 已完成（會自動變色） |
| 改價格／下架商品 | 改「商品」工作表的售價，或把「上架」改成「否」 |
| 改通知信箱 | 「設定」工作表的「通知Email」（可填多個，用逗號分隔） |
| 臨時暫停接單 | 「設定」→「暫停接單」改成「是」 |
| 每晚收營業摘要 | 試算表選單「禾煎訂單 → 設定每日營業報表」 |

> **注意：** 網站上的商品價格寫在 `index.html`。如果在試算表改了價格，記得網站也要同步修改。否則顧客在網站看到的金額，會和實際成立的金額不同（訂單一律以試算表價格為準）。

## 五、修改程式後要重新部署

改了 `Code.gs` 之後，要到 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本：新版本 → 部署**，網址不會改變。

## 安全設計

- **價格防竄改**：金額一律由試算表「商品」的價格重新計算，網站送來的價格不會被採用。
- **防重複下單**：同一支手機 20 秒內只接受一筆訂單。
- **流水號不重複**：每日流水號在鎖定下產生，例如 `HJ261127-0001`。
- **防公式注入**：輸入內容會檢查並跳脫試算表公式，避免被當成公式執行。
- **查詢需驗證**：訂單查詢 API 需要同時提供訂單編號與手機號碼。
